# 本项目有关
 * 这是一个使用 人工反编译APK 溜溜梅还原Haxe源代码 并且做到可编译与最大化等效还原的一个逆向项目

 * 使用以下工具：jadx apktool 儿子网络5.5 旮旯木5.3闪光

 * 本项目以最大化等效还原为目标，因为从一开始反编译出完整的原本源代码就是不可能的事情，并确保了代码的可读性

 * 本项目已经在Windows平台确认可通过编译并且正常游玩

> 因原PsychEngine不包含NOTICE文件本仓库也不包含
> 
> 本项目使用Apache 2.0协议开源
